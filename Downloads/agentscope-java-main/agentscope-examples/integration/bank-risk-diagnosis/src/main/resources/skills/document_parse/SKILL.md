# 文档解析指南

## 概述

本文档定义银行机构风险诊断中文档解析的方法论。文档解析由 Java `DocumentParserService` 完成，包括 OFD 电子文档解析（Apache OFDRW）、Word 文档解析（Apache POI XWPF）、Excel 表格解析（Apache POI XSSF/HSSF）。

## 支持的文档类型

| 类型 | 扩展名 | 来源 | 提取内容 |
|------|--------|------|----------|
| OFD | .ofd | 监管检查意见书、行政处罚决定书、检查通报 | 全文文本 |
| Word | .doc/.docx | 审计报告、风险排查报告、上级检查反馈 | 正文、表格、标题结构 |
| Excel | .xls/.xlsx | 问题清单、整改台账 | Sheet名、表头、数据行 |

## 文档来源与用途

根据文档来源确定在风险分析中的用途：

| 来源 | 文档特征 | 关注重点 |
|------|----------|----------|
| 监管检查 | 以监管要求为基准，列举违规事项 | 合规风险、处罚风险 |
| 内部审计 | 以制度流程为基准，发现流程缺陷 | 操作风险、制度执行 |
| 上级检查 | 跨机构对比，发现管理短板 | 经营风险、管理问题 |
| 整改台账 | 历史问题及整改状态 | 整改效率、重复问题 |

## 解析质量检查

解析完成后需验证：
1. 内容不为空
2. 表格数据完整（行数、列数正确）
3. 中文编码正确，无乱码
4. 保留文档结构（章节、层级关系）
