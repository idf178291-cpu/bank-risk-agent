# 风险趋势分析指南

## 任务

基于已提取和分类的风险问题，分析短期和长期风险趋势。

## 短期趋势分析（近一年）

分析维度：

### 1. 新增问题趋势
- 最近一个季度/半年/一年的新增问题数量
- 是否有加速增长趋势
- 新发现的问题主要集中在哪些风险类别

### 2. 整改效率趋势
- 问题的平均整改周期
- 逾期未整改问题的比例
- 整改完成率是否在提升

### 3. 复发率趋势
- 已整改问题中复发比例
- 同类问题在不同检查中反复出现的次数

## 中长期趋势分析（未来1-3年）

分析维度：

### 1. 管理能力趋势
- 制度建设是否在完善
- 流程控制是否在加强
- 人员素质是否在提升

### 2. 风险传导趋势
- 某类风险是否会传导至其他类别
- 操作风险→合规风险的传导可能性
- 信用风险→声誉风险的传导可能性

### 3. 外部环境影响
- 监管政策趋严对合规风险的影响
- 经济下行对信用风险的影响
- 技术变革对安全风险的影响

## 趋势判断准则

| 趋势 | 判断条件 |
|------|----------|
| 改善 | 新增问题↓、整改率↑、复发率↓ |
| 稳定 | 各项指标波动在±20%内 |
| 恶化 | 新增问题↑、整改率↓、复发率↑ |

## 输出格式

```json
{
  "shortTermTrend": "短期（近一年）风险趋势描述，包含数据支撑",
  "longTermTrend": "中长期（未来1-3年）风险趋势预判，包含分析依据",
  "overallDirection": "IMPROVING / STABLE / WORSENING",
  "keyIndicators": {
    "newIssueGrowthRate": "+15%",
    "rectificationRate": "68%",
    "recurrenceRate": "22%"
  },
  "emergingRisks": ["新出现的风险类型或信号"]
}
```
