# 六大风险分类指南

## 分类体系

### 1. 信用风险 (CREDIT_RISK)

主要指借款人或交易对手未能履行合同义务导致损失的风险。

**典型问题类型：**
- 贷款管理：贷前调查不实、贷款审批不规范、贷款用途监控缺失
- 授信管理：超授权授信、集中度超标、关联交易管理薄弱
- 资产质量：不良贷款处置、抵债资产管理、拨备不足
- 担保管理：抵质押物估值不实、保证人资质审查不严

**关键词：** 不良贷款、逾期、垫款、授信、担保、抵押、质押、五级分类、拨备

### 2. 操作风险 (OPERATION_RISK)

主要指内部流程、人员、系统缺陷或外部事件导致损失的风险。

**典型问题类型：**
- 柜面操作：现金管理、印章管理、凭证管理、对账管理
- 业务流程：流程缺失、流程执行不到位、缺乏有效控制
- 员工违规：越权操作、利益输送、内外勾结
- 系统缺陷：系统功能不完善、数据不一致、交易异常

**关键词：** 操作失误、流程缺陷、违规操作、越权、印章、凭证、对账

### 3. 安全风险 (SECURITY_RISK)

主要指信息科技安全、物理安全和业务连续性方面的风险。

**典型问题类型：**
- 网络安全：漏洞管理、入侵防护、网络隔离
- 数据安全：客户信息泄露、数据备份不足、敏感数据未脱敏
- 权限管理：账号权限过大、未定期清理、离职人员账号未注销
- 物理安全：机房管理、监控覆盖不足、消防隐患

**关键词：** 网络安全、数据泄露、权限、账号、备份、灾备、机房

### 4. 合规风险 (COMPLIANCE_RISK)

主要指违反法律法规、监管规定或行业准则导致的风险。

**典型问题类型：**
- 反洗钱：客户身份识别、大额交易报告、可疑交易监测
- 监管处罚：行政处罚、监管意见、整改要求未落实
- 制度执行：制度不健全、制度执行不到位、制度培训不足
- 法律风险：合同管理、诉讼案件、知识产权

**关键词：** 反洗钱、处罚、监管、违规、制度、合规、法律、诉讼

### 5. 战略与经营风险 (STRATEGY_RISK)

主要指战略决策失误、经营模式失效或外部环境变化导致的风险。

**典型问题类型：**
- 战略执行：战略目标未达成、业务转型受阻、资源配置不合理
- 业务结构：收入来源过于集中、产品竞争力下降、客户流失
- 经营偏离：偏离主业、盲目扩张、创新业务风险失控
- 盈利能力：利润下滑、成本控制不力、定价不合理

**关键词：** 战略、经营、盈利、收入、成本、业务结构、市场份额

### 6. 声誉风险 (REPUTATION_RISK)

主要指负面舆情、客户投诉或品牌损害导致的风险。

**典型问题类型：**
- 投诉：客户投诉量增加、投诉处理不及时、同类投诉反复发生
- 负面舆情：媒体报道、社交媒体传播、监管部门点名
- 媒体曝光：重大负面事件被媒体广泛报道
- 品牌损害：客户满意度下降、合作机构减少

**关键词：** 投诉、舆情、媒体、曝光、声誉、品牌、满意度

## 分类原则

1. 当一个问题同时符合多个分类时，选择最核心最直接的风险类别
2. 如果问题涉及监管处罚，优先归类为合规风险
3. 如果问题涉及客户资金损失，优先归类为信用风险
4. 如果问题涉及系统或数据，优先归类为安全风险

## 分类名称匹配规则

用户或文档可能使用不同方式指代同一分类，按以下规则识别：

- 英文枚举名（大小写不敏感）：`CREDIT_RISK` / `credit_risk` → 信用风险
- 中文全称包含匹配：`信用` → 信用风险，`合规` → 合规风险，`操作` → 操作风险
- 中文简称：`安全` → 安全风险，`战略` / `经营` → 战略与经营风险，`声誉` / `舆情` → 声誉风险
- 无法匹配时明确回复"未知分类"而非猜测

## 输出格式

按六大类别输出分组后的分类结果：
```json
{
  "creditRisk": [问题列表],
  "operationRisk": [问题列表],
  "securityRisk": [问题列表],
  "complianceRisk": [问题列表],
  "strategyRisk": [问题列表],
  "reputationRisk": [问题列表]
}
```

每个问题需包含 riskCategory 和 riskLevel 字段。
