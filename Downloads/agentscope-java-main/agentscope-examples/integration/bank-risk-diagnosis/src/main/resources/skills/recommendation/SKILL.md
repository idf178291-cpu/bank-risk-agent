# 风险防控建议生成指南

## 生成原则

1. **规则优先**：常见问题类型有标准处理建议，直接输出
2. **风险为本**：高风险问题优先，整改建议需具体可落地
3. **分层建议**：区分紧急处置、短期整改、长期制度建设三个层次

## 六大风险类别标准建议

### 信用风险
- 贷后检查薄弱 → 建立标准化贷后检查模板，明确检查频率和内容；实施贷后检查质量考核
- 授信审批不规范 → 优化授信审批流程，实施AB角双签制度；建立关联交易自动识别
- 不良贷款处置缓慢 → 制定不良贷款清收计划，明确时间表和责任人；探索不良资产证券化

### 操作风险
- 柜面操作违规 → 加强柜面操作培训，实施双人复核制度；部署智能监控系统自动预警
- 流程管控缺失 → 梳理核心业务流程，建立关键控制点清单；实施定期流程穿行测试
- 员工违规操作 → 强化员工行为排查，建立异常交易监测模型；加大违规处罚力度

### 安全风险
- 网络安全漏洞 → 定期开展渗透测试和漏洞扫描；建立安全事件响应SOP
- 数据安全问题 → 实施数据分级分类管理；落实数据脱敏和访问控制
- 权限管理混乱 → 开展权限治理专项行动；实施最小权限原则和定期复核机制

### 合规风险
- 反洗钱管理不足 → 升级可疑交易监测模型；增加客户风险评级复核频次
- 监管制度执行不到位 → 建立监管法规跟踪机制；实施合规培训全员覆盖
- 合同管理不规范 → 建立标准化合同模板库；实施合同审查电子化流程

### 战略与经营风险
- 业务结构单一 → 推进业务多元化战略；定期评估业务条线风险回报
- 盈利能力下滑 → 实施成本精细化管理；优化存贷款定价策略
- 资源配置不合理 → 建立资产负债管理动态优化模型

### 声誉风险
- 客户投诉增加 → 建立投诉分析机制，识别系统性问题；优化投诉处理SLA
- 负面舆情管理 → 建立舆情监测和预警系统；制定危机公关预案

## 输出格式

```json
[
  {
    "category": "CREDIT_RISK",
    "priority": "HIGH",
    "issue": "针对的的具体问题",
    "recommendation": "具体建议内容",
    "timeframe": "EMERGENCY / SHORT_TERM / LONG_TERM",
    "responsibleDept": "责任部门建议"
  }
]
```

## 质量要求

- 每条建议必须对应一个已识别的问题
- 紧急建议（EMERGENCY）对应 CRITICAL 级别问题
- 每条建议需要有可量化的执行标准
- 避免笼统建议，如"加强管理"、"提高认识"
