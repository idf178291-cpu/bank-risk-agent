## 风险等级色标

报告中必须使用以下色标：
- 🔴 严重 / 高风险：红色标记
- 🟠 高风险：橙色标记
- 🟡 关注：黄色标记
- 🟢 低风险 / 达标：绿色标记

## 证据链要求

每个重点风险主题必须包含：
1. 原文摘录（sourceExcerpt）
2. 来源文件名（sourceFile）
3. 至少2条来自不同文档的独立证据
