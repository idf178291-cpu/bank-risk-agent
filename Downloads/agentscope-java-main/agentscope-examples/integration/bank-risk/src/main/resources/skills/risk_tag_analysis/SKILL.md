# 商业银行客户风险标签分析

## 使用原则

本技能用于逐项分析客户风险标签，每个标签独立判断风险状态，**不进行量化打分、不加权聚合、不产出综合风险等级**。客户经理应结合多个标签的交叉信号，形成整体判断。

---

## 一、客户预警等级

### 标签说明

预警等级是银行内部根据客户多维度风险特征综合评定的预警分类，反映对客户风险的整体判断。

### 风险判定

| 预警等级 | 风险状态 | 判定说明 |
|----------|----------|----------|
| 红色 | 高风险 | 多项风险指标显著恶化，存在实质性违约风险或重大经营危机 |
| 橙色 | 中风险 | 部分指标出现预警信号，经营或财务出现不利变化，需密切关注 |
| 蓝色 | 关注 | 个别指标接近警戒线，风险虽有上升但整体可控 |
| 无预警 | 正常 | 当前未触发风险预警阈值，各类指标处于正常范围 |

### 管理建议

**红色预警客户：**
- 纳入重点监控名单，每月至少现场走访一次
- 逐笔评估信贷资产安全，制定风险处置预案
- 限制新增授信，存量授信逐步压缩或要求増信
- 按月向分行风险管理部提交专项报告

**橙色预警客户：**
- 加密贷后检查频次（不低于每月一次）
- 重点核实预警指标的真实状况，排查是否存在未暴露风险
- 审慎审批新增授信，确需投放的须报上级审批
- 每季度完成风险重评估

**蓝色预警客户：**
- 在常规贷后管理基础上增加专项跟踪
- 核实预警信号的成因及后续变化趋势
- 可正常续作存量业务，新增授信需在贷前报告中说明预警情况

**无预警客户：**
- 执行常规贷后管理流程
- 关注外部环境变化可能对客户产生的传导风险

## 二、RAD 分 & 预警分

### 标签说明

RAD 分（Risk Assessment Dimension）和预警分均为银行内部风险评分工具，**分值越高代表风险越低**，分值越低代表风险越高。

两种分数通常由风控模型基于征信数据、财务指标、账户行为、外部信息等多个维度自动计算产出，定期更新。

### 风险判定

分析时需关注分数所处的绝对区间、近期变化趋势、以及与同行业客户的相对位置：

| 分数状态 | 风险信号 |
|----------|----------|
| 分数持续下降 | 风险上升信号，即使仍在安全区间，需关注下降原因 |
| 分数骤降（单次下降 > 15%） | 强风险信号，需立即排查触发因素 |
| 分数长期处于尾部区间 | 结构性风险，需评估客户基本面是否已恶化 |
| 分数显著低于同业均值 | 相对风险偏高，需结合其他标签判断是否为行业共性 |

### 管理建议

**分数持续下降的客户：**
- 追踪下降的驱动因子（征信查询异常、负债率上升、现金流恶化等）
- 判断下降是周期性波动还是趋势性恶化
- 根据驱动因子匹配相应管理措施

**分数骤降的客户：**
- 24 小时内联系客户核实是否发生重大负面事件
- 排查是否存在未上报的债务违约、法律诉讼等
- 向上级风险主管报告，启动临时风险监控

**分数尾部区间的客户：**
- 结合其他标签判断是否已达到预警条件
- 在后续信贷审批中作为重要参考因素
- 如无信贷余额，审慎评估准入资格

**分数正常的客户：**
- 定期关注分数变动，纳入常规监控

## 三、ESG 分类分

### 标签说明

ESG 分类分是银行基于企业在环境（Environmental）、社会（Social）、公司治理（Governance）三个维度的表现进行的分类评定。

### 风险判定

| ESG 分类 | 风险状态 | 判定说明 |
|----------|----------|----------|
| 红色 | 高风险 | ESG 表现严重不达标，存在重大环境/社会/治理问题 |
| 黄色一级 | 较高风险 | ESG 存在明显缺陷，但尚不构成重大违规 |
| 黄色二级 | 关注 | ESG 部分指标不理想，需整改提升 |
| 蓝色 | 正常 | ESG 表现良好，无明显风险隐患 |

### 业务限制

**红色与黄色二级及以上客户不得开展新业务**，具体规则：

| ESG 分类 | 新增授信 | 存量续作 | 其他业务合作 |
|----------|----------|----------|-------------|
| 红色 | 禁止 | 到期收回，不予续作 | 禁止建立任何新业务关系 |
| 黄色一级 | 禁止 | 需风控会审议、报分行审批 | 仅可维持一般结算业务 |
| 黄色二级 | 禁止 | 审慎评估，需提供整改证明 | 限制非信贷类高风险业务 |
| 蓝色 | 正常审批 | 正常续作 | 正常开展 |

### 管理建议

**红色 ESG 客户：**
- 严格执行业务禁入政策，不得新增任何授信和业务关系
- 制定存量业务退出计划，明确退出时间表
- 跟踪企业 ESG 整改进展，待分类上调后方可重新评估准入
- 关注 ESG 问题可能引发的监管连带风险

**黄色客户（一级/二级）：**
- 向客户发送 ESG 整改建议函，要求限期提供整改方案和时间表
- 存量业务可维持但不得扩大，授信到期后视整改情况决定是否续作
- 每季度跟踪整改进展，核实企业是否按计划执行
- 整改完成且分类上调至蓝色后，方可申请恢复业务准入
- 关注同行业 ESG 政策变化，预防因行业标准提高导致分类恶化

**蓝色 ESG 客户：**
- 将 ESG 指标纳入常规贷后管理
- 关注行业 ESG 监管政策变化，提前预判对客户的可能影响

## 四、资产分类

### 标签说明

资产分类按照监管要求对信贷资产进行风险分级，是衡量信贷资产质量的核心指标。

### 分类体系与风险判定

#### 正常类

| 分类 | 含义 | 风险判定 |
|------|------|----------|
| A1 | 正常一级 | 借款人经营正常，偿债能力充足，第一还款来源有充分保障 |
| A2 | 正常二级 | 借款人经营基本正常，偿债能力较好，存在不影响还款的轻微不利因素 |
| A3 | 正常三级 | 借款人经营正常但存在一定不确定性，或偿债能力一般 |
| A4 | 正常四级 | 借款人经营尚可但存在不利发展趋势，或偿债能力需关注 |

#### 关注类

| 分类 | 含义 | 风险判定 |
|------|------|----------|
| B1 | 关注一级 | 出现可能影响还款的不利因素，目前虽能正常还款但未来存在不确定性 |
| B2 | 关注二级 | 不利因素较为明显，借款人依靠正常经营收入已不足以足额偿还本息 |
| B3 | 关注三级 | 借款人经营出现困难，依靠自身能力已难以维持正常还款 |

#### 不良类

| 分类 | 含义 | 风险判定 |
|------|------|----------|
| C1 | 次级一级 | 还款能力出现明显问题，依靠正常经营收入无法足额偿还本息，但执行担保仍可覆盖 |
| C2 | 次级二级 | 还款能力严重不足，担保覆盖存在缺口，预计存在一定损失 |
| D1 | 可疑一级 | 借款人无法足额偿还本息，即使执行担保也肯定会形成较大损失 |
| D2 | 可疑二级 | 借款人基本丧失还款能力，预计损失金额较大但具体比例尚难确定 |
| E1 | 损失级 | 采取所有可能措施和法律程序后，本息仍无法收回或仅能收回极少部分 |

### 不良客户判定

以下分类属于**不良客户**：**C1、C2、D1、D2、E1**

不良客户在监管报送、拨备计提、内部考核等方面均按不良资产管理。

### 管理建议

**正常类客户（A1-A4）：**
- A1-A2：常规贷后管理，关注经营和行业变化
- A3-A4：加强跟踪监测，核实不利因素的发展趋势，按正常频次执行贷后检查

**关注类客户（B1-B3）：**
- B1：加密贷后检查频次（每月至少一次），核实不利因素的具体影响
- B2：评估是否需要追加担保措施，限制新增授信，制定风险缓释方案
- B3：启动风险预警流程，24 小时内联系客户了解经营困难的具体情况，由客户经理和风险经理共同制定处置方案

**不良类客户（C1-E1）：**
- C1-C2：立即冻结可用授信额度，启动担保处置评估，法律顾问介入，按不良资产管理要求执行
- D1-D2：全面评估预计损失金额，计提相应拨备，启动法律追偿程序，关注担保物价值变化
- E1：完成损失认定，启动核销程序（符合核销条件时），继续追偿不因核销而放弃债权

## 五、风险标签分析法

除前四节的专业标签外，系统中还存在大量直接反映风险状态的标签，其典型特征为：

- 标签名称多为「是否 xxx」的二元判定
- 标签值「是」即为风险信号本身，无需通过其他指标间接推断
- 标签值「否」仅表示未触发该风险，不等同于整体风险低

### 5.1 风险本质识别

拿到一个标签，首先判断它属于哪一类风险信号。风险标签通常指向以下范畴：

| 风险范畴 | 标签名称常见关键词 | 标签为「是」时的直接含义 |
|----------|-------------------|------------------------|
| 债务压力 | 债委会、借新还旧、展期、重组、以贷还贷、以贷收息 | 企业偿债已出现困难，依赖外部协调或借新维持 |
| 融资异常 | 多头授信、过度融资、融资集中、民间借贷、高息融资 | 融资渠道或额度超出正常经营所需，资金链脆弱 |
| 信用劣化 | 逾期、欠息、垫款、征信不良、失信被执行、限高 | 企业或实控人信用记录已出现污点 |
| 资金挪用 | 贷款挪用、资金回流、虚假用途、资金归集异常 | 贷款未按约定用途使用，实际资金去向不明 |
| 合规红线 | 环保处罚、税务违法、非法集资、洗钱嫌疑、行业禁入 | 企业涉及违法违规，可能面临处罚或经营限制 |
| 治理缺陷 | 空壳企业、虚假注资、实控人失联、高管涉案、审计非标 | 企业治理结构或信息真实性存在严重问题 |
| 经营异常 | 停工停产、大幅裁员、核心客户流失、资质吊销、退市风险 | 企业经营已出现实质性中断或重大不利变化 |
| 担保隐患 | 互保联保、担保圈、过度担保、担保代偿 | 或有负债可能转化为真实负债 |
| 关联风险 | 关联挪用、关联担保、资金归集、集团风险传导 | 关联方之间的风险可能互相传染 |
| 还款能力 | 一还不足、二还不覆盖、还款来源不明、现金流为负 | 偿债能力本身存在缺陷 |

### 5.2 逐个标签分析流程

面对任意一个风险标签，按以下流程逐个分析：

**第一步：确认标签含义**

标签名称通常已表明其含义。如果标签名称自解释性强（如「是否债委会客户」），直接进入第二步。如名称含义不明确，从标签的风险范畴推断其指向。

**第二步：根据标签值给出风险判断**

| 标签值 | 分析方向 |
|--------|----------|
| 是 | 该风险信号已触发。分析该信号对企业偿债能力的具体影响路径，以及信号本身的严重程度 |
| 否 | 当前未触发该风险信号，记录为正常。如该标签与客户所属行业/类型高度相关（如产能过剩行业未触发「停工停产」），可简要说明未触发的原因推测 |
| 不适用/未采集 | 标签值缺失本身需关注——是该维度未被监控，还是数据未同步？建议核实标签的有效性 |

**第三步：产出管理建议**

管理建议必须与标签指向的风险直接挂钩，逻辑链为：

```
标签值 → 风险已触发 → 影响路径 → 建议行动
```

建议需明确紧急程度（立即行动 / 主动核查 / 持续关注），如涉及硬性制度约束直接引述。

### 5.3 分析示例

以下示例展示如何将上述流程应用到具体风险标签。**任何风险标签均遵循相同流程，不依赖枚举清单**。

**示例 A：标签「是否债委会客户」，取值「是」**

- 风险范畴：债务压力
- 风险判断：企业已加入债权人委员会，说明此前已发生债务违约或面临严重的债务偿付困难，多家金融机构已介入协调。债委会的成立本身意味着企业的自主偿债能力已严重受损。需进一步了解债委会的成立时间、涉及债务规模、目前的化债方案以及本行在债委会中的角色和表决权。
- 管理建议：立即向风险管理部报告，确认本行在债委会中的席位和表决权；评估化债方案对本行信贷资产的影响；无论化债方案如何，该类客户不得新增授信；如需展期或重组，须经分行贷审会审议。

**示例 B：标签「是否借新还旧」，取值「是」**

- 风险范畴：债务压力
- 风险判断：企业当前现金流不足以通过经营收入偿还到期贷款，依赖"借新还旧"维持。这可能是暂时的流动性周转问题，也可能是结构性的偿债能力不足。需结合借新还旧的频率和持续时间判断——如果仅发生一次且金额较小，可能是阶段性周转；如果连续多期或多笔贷款均依赖借新还旧，则是结构性风险。
- 管理建议：核实借新还旧的触发原因，是由经营性现金流不足还是由临时性大额支出所致；如需继续办理借新还旧，须按监管要求下调资产分类；评估企业经营改善的可能性，设定明确的退出借新还旧的时间节点。

**示例 C：标签「是否多头授信」，取值「是，涉及 6 家银行」**

- 风险范畴：融资异常
- 风险判断：企业在 6 家银行同时有授信，可能超出其正常经营所需的融资规模。多头授信叠加总敞口不明，一旦其中一家银行抽贷可能引发连锁反应。需穿透了解企业在其他银行的授信余额、担保方式和还款情况。如果各行之间缺乏信息共享，银行端对企业的真实负债规模可能低估。
- 管理建议：通过征信报告和同业信息摸清企业在各行的授信总额和余额；评估总负债是否与企业经营规模匹配；如发现过度融资迹象（总负债超出合理范围），制定敞口压缩计划；加强与同业的信息沟通，避免因信息不对称导致的误判。

### 5.4 多个风险标签的分析

当一次查询涉及多个风险标签时，逐一独立分析，**不进行跨标签加权合成**。但客户经理应关注以下叠加模式：

- 同一风险范畴内多个标签同时为「是」（如「债委会客户」+「借新还旧」+「展期」），说明该范畴的风险已不是孤立事件，而是系统性问题
- 不同范畴的标签相互印证（如「资金挪用」与「多头授信」同时为「是」），风险可信度更高，需联合制定处置方案
- 标签值「是」的数量本身是信号——触发标签越多，企业的风险面越广，但不因此产出量化评分

## 六、标签交叉分析指引

不产出综合分数，但客户经理应重点关注以下交叉信号：

| 交叉信号 | 风险含义 |
|----------|----------|
| 预警红色 + 资产分类 B2 及以上 | 风险高度集中，两大核心标签同时指向严重风险 |
| ESG 红色/黄色 + 预警橙色及以上 | ESG 问题可能进一步触发其他风险标签恶化 |
| RAD 分骤降 + 资产分类尚在 A 区间 | 资产分类可能存在滞后，需排查是否低估了风险 |
| 资产分类进入不良 + 预警绿色/无预警 | 预警系统可能存在延迟，需人工复核预警阈值 |
| ESG 黄色 + RAD 分持续下降 | 需关注是否因 ESG 整改成本导致财务状况恶化 |
| 多个标签同时发生级别迁移 | 系统性风险信号，不应视为孤立的标签变动 |

### 标签迁移处理

当客户风险标签发生级别迁移时（如预警从蓝色升至橙色、资产分类从 A4 下调至 B1）：

- 分析迁移的触发因素，判断是一次性事件还是趋势性变化
- 评估迁移是否可能引发其他标签的连锁反应
- 根据新级别的管理要求及时调整管控措施
- 记录迁移原因和处理措施，作为后续审计追溯的依据
