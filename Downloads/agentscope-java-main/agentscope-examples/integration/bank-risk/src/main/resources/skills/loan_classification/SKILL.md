# 企业信用评级参考

## 信用等级定义

| 等级 | 定义 | 对应征信评分 | 违约概率 |
|------|------|-------------|----------|
| AAA | 偿债能力极强，基本不受不利经济环境影响 | 90-100 | < 0.1% |
| AA | 偿债能力很强，受不利经济环境影响较小 | 80-89 | 0.1%-0.5% |
| A | 偿债能力较强，但较易受不利经济环境影响 | 70-79 | 0.5%-1% |
| BBB | 偿债能力一般，不利经济环境下偿债能力可能减弱 | 60-69 | 1%-3% |
| BB | 偿债能力较弱，持续不确定性较大 | 45-59 | 3%-8% |
| B | 偿债能力较大程度依赖外部环境 | 30-44 | 8%-15% |
| CCC | 高度依赖经济环境，偿债能力极度不确定 | 20-29 | 15%-30% |
| CC | 破产或重组中，但仍可部分偿债 | 10-19 | 30%-50% |
| D | 已发生违约或破产清算 | 0-9 | > 50% |

## 评级调整因子

### 正面调整（可上调1-2个子级）
- 行业龙头地位稳固，市场份额 > 30%
- 经营性现金流连续3年 > 净利润
- 实际控制人背景雄厚（央企/国企/知名企业集团）
- 持有核心专利/特许经营权等稀缺资源

### 负面调整（可下调1-3个子级）
- 存在未决重大诉讼（涉案金额 > 净资产的20%）
- 近2年内发生实际控制人变更
- 审计报告为非标准无保留意见
- 征信查询频率异常（6个月 > 10次）

## 评级迁移预警信号

### 财务预警
- ROA 连续2年下降 > 50%
- 资产负债率年增幅 > 10个百分点
- 毛利率年降幅 > 5个百分点
- 经营现金流/营业收入 < 0

### 非财务预警
- 核心管理层大规模离职
- 主要客户/供应商终止合作
- 被列入失信被执行人名单
- 同业融资利率显著高于市场水平

## 行业风险调整

| 行业 | 基础评级上限 | 特殊调整 |
|------|-------------|----------|
| 新能源 | AAA | 技术迭代风险 -1~2级 |
| 通信设备 | AAA | 地缘政治风险 -1~2级 |
| 新能源汽车 | AAA | 补贴政策风险 -1级 |
| 房地产 | BBB | 政策调控风险 -2~3级 |
| 航空运输 | A | 外部冲击风险 -2级 |
| 信息技术 | AAA | 客户集中度风险 -1级 |
