# 贷款五级分类标准

## 五级分类定义

| 分类 | 定义 | 拨备要求 |
|------|------|----------|
| 正常 (Normal) | 借款人能够履行合同，有充分把握按时足额偿还本息 | 1% |
| 关注 (Special Mention) | 借款人目前有能力偿还，但存在可能对偿还产生不利影响的因素 | 2% |
| 次级 (Substandard) | 借款人还款能力出现明显问题，依靠正常经营收入无法足额偿还本息 | 25% |
| 可疑 (Doubtful) | 借款人无法足额偿还本息，即使执行担保也肯定会造成较大损失 | 50% |
| 损失 (Loss) | 在采取所有可能措施或法律程序后，本息仍无法收回或只能收回极少部分 | 100% |

## 分类迁移规则

### 向下迁移（恶化信号）
- 正常 → 关注：出现逾期 1-30 天，或外部负面舆情
- 关注 → 次级：逾期 31-90 天，或核心经营指标明显恶化
- 次级 → 可疑：逾期 91-180 天，或担保出现代偿困难
- 可疑 → 损失：逾期 > 180 天，或借款人进入破产程序

### 向上迁移（改善条件）
- 关注 → 正常：连续6个月正常还款，不利因素消除
- 次级 → 关注：逾期款项全部偿还，经营状况实质性改善
- 可疑 → 次级：有效担保实现或部分债务重组成功
- 损失 → 可疑：核销后部分回收有明确预期

## 早期预警信号

### 财务信号
- 流动比率持续下降
- 应收账款周转天数显著增加
- 毛利率/净利率快速下滑
- 经营性现金流为负

### 非财务信号
- 实际控制人或核心管理层变更
- 主要股东股权被司法冻结
- 被列入失信被执行人名单
- 同业授信政策收紧或退出

### 银行业特有信号
- 资本充足率在6个月内下降超过2个百分点
- 不良贷款率在连续两个季度上升
- 拨备覆盖率在一年内下降超过30个百分点
- 核心负债依存度低于60%

## 分类频次要求
- 正常类：至少每半年分类一次
- 关注类：至少每季度分类一次
- 次级及以下：至少每月分类一次
- 发生重大风险事件时：立即重新分类
