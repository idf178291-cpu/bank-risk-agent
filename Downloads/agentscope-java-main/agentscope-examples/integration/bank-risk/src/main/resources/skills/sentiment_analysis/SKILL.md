# 商业银行客户舆情风险分析框架

## 一、舆情分类体系

对目标企业相关的公开舆情按性质归类，判定其风险指向：

| 类别 | 代码 | 典型事件 | 核心风险指向 |
|------|------|----------|-------------|
| 监管处罚 | REG | 行政处罚、立案调查、行业禁入、产品召回 | 合规风险、经营中断 |
| 财务危机 | FIN | 债务违约、评级下调、融资受阻、现金流断裂 | 直接偿债风险 |
| 治理动荡 | GOV | 实际控制人变更、高管集体离职、股权冻结/拍卖 | 管理真空、战略失向 |
| 经营事故 | OPS | 安全事故、环境污染、数据泄露、供应链断裂 | 经营中断、赔偿损失 |
| 法律纠纷 | LAW | 重大诉讼、仲裁、资产查封、破产申请 | 直接财务损失 |
| 市场传言 | RUM | 做空报告、媒体负面报道、社交媒体发酵 | 声誉风险、融资收紧 |
| 政策变化 | POL | 行业调控收紧、补贴取消、准入限制 | 行业系统性风险 |

### 多标签规则

同一舆情事件可归属多个类别。例如：
- 环保处罚 → REG + OPS
- 债券违约 + 媒体炒作 → FIN + RUM
- 实控人被调查 → GOV + REG

## 二、舆情评分卡

> **方法论说明**：本评分卡采用银行业操作风险管理中常见的「风险矩阵」思想（影响 × 传播力 × 时效），参考了监管舆情分类指引和国有大行舆情监测实践。评分结果反映该事件对企业风险画像的冲击程度，不直接等同于信贷资产损失。

### 2.1 评分流程

```
1. 严重度评级 (S): 判断事件本身的性质和潜在损失
2. 媒体权重 (M): 根据传播源和传播范围调节
3. 时效衰减 (T): 根据距今时间计算衰减
4. 单事件分 = S × M × T
5. 综合等级 = max(所有单事件分)   ← 银行审贷中的"最差情形"原则
```

### 2.2 严重度 (Severity)

| 等级 | 分值 | 判定标准 |
|------|------|----------|
| S1 - 轻微 | 1 | 单一负面报道，无实质财务或经营影响 |
| S2 - 一般 | 2 | 涉及行政处罚或一般诉讼，金额 < 净资产 5% |
| S3 - 关注 | 3 | 涉及重大诉讼/处罚，金额达净资产 5%-20%，或核心高管变动 |
| S4 - 严重 | 4 | 债务违约、资产冻结、实际控制人涉案、行业资质暂停 |
| S5 - 危机 | 5 | 破产申请、强制退市、经营许可证吊销、大规模挤兑 |

### 2.3 媒体权重 (Media Weight)

| 传播层级 | 权重 | 典型来源 |
|----------|------|----------|
| 社交端 | 0.5 | 微博/雪球/股吧单一用户发布，未形成转发链 |
| 自媒体 | 0.7 | 公众号/头条号/行业自媒体发布，阅读量 < 10万 |
| 财经媒体 | 0.9 | 第一财经/财新/21世纪/每日经济新闻等专业财经媒体 |
| 官媒/监管 | 1.0 | 新华社/人民日报/央视等央媒，或证监会/银保监/交易所公告 |
| 病毒传播 | 1.2 | 24 小时内微博热搜 + 多平台转发量 > 50万，形成公众事件 |

**叠加规则**：同一事件被多层级媒体报道时取最高权重；官媒转载自媒体信息时按官媒权重计。

### 2.4 时效衰减 (Time Decay)

采用指数衰减模型：`T = 0.95^天数`（天数 = 事件发生日至今的天数）

| 距今 | 衰减系数 | 说明 |
|------|----------|------|
| 7 天 | 0.70 | 新近发生，热度尚在 |
| 14 天 | 0.48 | 热度明显消退 |
| 30 天 | 0.21 | 除持续发酵外，影响有限 |
| 60 天 | 0.046 | 归档阈值以下 |
| 90 天 | 0.010 | 基本不再影响评级 |

> **例外**：事件有重大新进展时，距离按最近进展日重新计算；持续发酵中的事件衰减系数锁定 ≥ 0.5。

### 2.5 综合舆情等级

采用「最差情形」原则取最高分：

| 最高单事件分 | 综合等级 | 含义 |
|-------------|----------|------|
| ≤ 0.5 | 低风险 | 常规关注即可 |
| 0.5 - 1.5 | 关注 | 需跟踪后续进展 |
| 1.5 - 3.0 | 高风险 | 需采取风险缓释措施 |
| > 3.0 | 严重 | 需立即启动应急处置 |

> **与旧版 S×C×D 的差异**：去掉了信用敞口权重 C——舆情严重性本身不会因为敞口大就更严重，敞口影响的是处置优先级（见下节），不应混入评级。

## 三、管理建议框架（按舆情等级）

### 3.1 低风险

**策略：常规跟踪**

- 记录舆情事件到客户档案
- 下次贷后检查时核实事件进展
- 无需主动联系客户

### 3.2 关注

**策略：主动跟踪**

- 3 个工作日内联系客户了解情况
- 收集事件相关佐证材料（公告、处罚决定书等）
- 在信贷管理系统中标记关注信号

### 3.3 高风险

**策略：风险缓释**

- 24 小时内联系客户财务负责人，要求书面说明
- 结合敞口优先级决定是否上报风险主管
- 评估是否需要追加担保/抵质押物
- 启动贷后专项检查，必要时现场走访
- 每周向风险管理部门汇报进展

### 3.4 严重

**策略：应急处置**

- 立即报告支行行长及分行风险管理部
- 2 小时内召开应急会议，研判影响程度
- 冻结未使用授信额度
- 评估交叉违约风险，排查关联企业敞口
- 法律顾问介入，准备债权保全措施
- 按监管要求报送重大风险事件
- 每日向总分行汇报事态进展

## 四、多事件聚合规则

评分卡对每条事件独立评分，综合评级取最高分（最差情形原则）。同时评估以下叠加效应：

### 4.1 同类别叠加

同一舆情类别（如 FIN）出现多条事件时——即使每条分值不高，但集中爆发说明该维度存在系统性风险。输出时标注：「X 类别 30 天内出现 N 条事件，建议排查该维度根本原因」。

### 4.2 跨类别叠加

存在 2 个及以上不同类别事件时——说明风险来自多个方向，企业基本面可能存在广泛压力。综合等级在最高分基础上上调一级。

### 4.3 时间趋势信号

| 信号 | 含义 |
|------|------|
| 近 7 天新增事件 ≥ 3 条 | 风险正在加速暴露，无论分值均升级关注 |
| 同一事件周期性复现 | 结构性风险，非一次性冲击 |
| 90 天内无新事件 | 可归档，旧事件清零 |

## 五、行业敏感性参考

不同行业对特定类别舆情的敏感度不同，作为严重度评级的辅助参考（不单独乘系数）：

| 行业 | 高敏感类别 | 评级参考 |
|------|-----------|----------|
| 新能源 | POL（政策退坡）、REG（环保处罚） | 同级别事件在新能源行业影响更持续，T 衰减可考虑 0.93^天数 |
| 通信设备 | REG（技术管制）、LAW（知识产权） | 涉及实体清单/技术禁令时 S 直接取 S4 以上 |
| 新能源汽车 | POL（补贴调整）、OPS（安全事故） | 安全事故在汽车行业的传播力通常达到「病毒传播」级别 |
| 房地产 | FIN（流动性）、POL（调控）、RUM（市场信心） | 三类叠加时综合等级直接上调两级 |
| 航空运输 | OPS（安全事故）、POL（航权/航线） | 安全事故在航空业默认按 S4 起评 |
| 信息技术 | LAW（数据合规）、REG（网络安全） | 涉及数据跨境可触发多法域监管，归入多个类别 |
