# 商业银行客户舆情风险分析框架

## 一、舆情分类体系

对目标企业相关的公开舆情按性质归类，判定其风险指向：

| 类别 | 代码 | 典型事件 | 核心风险指向 |
|------|------|----------|-------------|
| 监管处罚 | REG | 行政处罚、立案调查、行业禁入、产品召回 | 合规风险、经营中断 |
| 财务危机 | FIN | 债务违约、评级下调、融资受阻、现金流断裂 | 直接偿债风险 |
| 治理动荡 | GOV | 实际控制人变更、高管集体离职、股权冻结/拍卖 | 管理真空、战略失向 |
| 经营事故 | OPS | 安全事故、环境污染、数据泄露、供应链断裂 | 经营中断、赔偿损失 |
| 法律纠纷 | LAW | 重大诉讼、仲裁、资产查封、破产申请 | 直接财务损失 |
| 市场传言 | RUM | 做空报告、媒体负面报道、社交媒体发酵 | 声誉风险、融资收紧 |
| 政策变化 | POL | 行业调控收紧、补贴取消、准入限制 | 行业系统性风险 |

### 多标签规则

同一舆情事件可归属多个类别。例如：
- 环保处罚 → REG + OPS
- 债券违约 + 媒体炒作 → FIN + RUM
- 实控人被调查 → GOV + REG

## 二、影响量化分级模型

### 2.1 单事件评分公式

```
事件风险分 = 严重程度(S) × 信用敞口权重(C) × 持续系数(D)
```

### 2.2 严重程度 (Severity)

| 等级 | 分值 | 判定标准 |
|------|------|----------|
| S1 - 轻微 | 1 | 单一负面报道，无实质财务或经营影响 |
| S2 - 一般 | 2 | 涉及行政处罚或一般诉讼，金额 < 净资产 5% |
| S3 - 关注 | 3 | 涉及重大诉讼/处罚，金额达净资产 5%-20%，或核心高管变动 |
| S4 - 严重 | 4 | 债务违约、资产冻结、实际控制人涉案、行业资质暂停 |
| S5 - 危机 | 5 | 破产申请、强制退市、经营许可证吊销、大规模挤兑 |

### 2.3 信用敞口权重 (Credit Exposure)

| 敞口类型 | 权重 | 说明 |
|----------|------|------|
| 仅结算户/存款 | 0.3 | 无信贷余额，仅存款业务往来 |
| 小额信贷 (< 1000万) | 0.5 | 贷款余额较小 |
| 中型信贷 (1000万-1亿) | 0.8 | 中等风险敞口 |
| 大型信贷 (> 1亿) | 1.0 | 重大风险敞口 |
| 银团牵头行 | 1.2 | 承担牵头责任，声誉风险叠加 |

### 2.4 持续系数 (Duration)

| 系数 | 适用场景 |
|------|----------|
| 0.5 | 一次性事件，已妥善解决 |
| 0.8 | 短期影响 (1-3个月可消化) |
| 1.0 | 中期影响 (3-12个月) |
| 1.5 | 长期影响 (> 1年) 或持续发酵中 |

### 2.5 综合风险等级

| 事件风险分 | 风险等级 | 含义 |
|-----------|----------|------|
| ≤ 0.5 | 低风险 | 常规关注即可 |
| 0.5 - 1.5 | 关注 | 需跟踪后续进展 |
| 1.5 - 3.0 | 高风险 | 需采取风险缓释措施 |
| > 3.0 | 严重 | 需立即启动应急处置 |

## 三、行业风险加权

不同行业对同类舆情的敏感度差异显著，综合评级时应乘以行业系数：

| 行业 | 系数 | 高敏感舆情类别 |
|------|------|---------------|
| 新能源 | 1.2 | POL (政策退坡), REG (环保处罚) |
| 通信设备 | 1.3 | REG (技术管制), LAW (知识产权) |
| 新能源汽车 | 1.1 | POL (补贴调整), OPS (安全事故) |
| 房地产 | 1.5 | FIN (流动性), POL (调控政策), RUM (市场信心) |
| 航空运输 | 1.3 | OPS (安全事故), POL (航权/航线) |
| 信息技术 | 1.0 | LAW (数据合规), REG (网络安全) |
| 一般制造业 | 1.0 | — |
| 批发零售 | 0.9 | — |

## 四、客户经理管理建议框架

### 4.1 低风险 (事件分 ≤ 0.5)

**策略：常规跟踪**

- 记录舆情事件到客户档案
- 下次贷后检查时核实事件进展
- 无需主动联系客户

### 4.2 关注 (事件分 0.5 - 1.5)

**策略：主动跟踪**

- 3 个工作日内联系客户了解情况
- 收集事件相关佐证材料（公告、处罚决定书等）
- 加密贷后检查频率（如从季度提升为月度）
- 在信贷管理系统中标记关注信号

### 4.3 高风险 (事件分 1.5 - 3.0)

**策略：风险缓释**

- 24 小时内联系客户财务负责人，要求书面说明
- 向上级风险主管报告，发起风险预警流程
- 评估是否需要追加担保/抵质押物
- 考虑压缩授信额度或调整还款计划
- 启动贷后专项检查，必要时现场走访
- 每周向风险管理部门汇报进展

### 4.4 严重 (事件分 > 3.0)

**策略：应急处置**

- 立即报告支行行长及分行风险管理部
- 2 小时内召开应急会议，研判影响程度
- 冻结未使用授信额度
- 评估交叉违约风险，排查关联企业敞口
- 法律顾问介入，准备债权保全措施
- 按监管要求报送重大风险事件
- 每日向总分行汇报事态进展

## 五、多事件聚合规则

当同一企业在观察窗口内（通常 30 天）存在多条舆情事件时：

1. **同类别叠加**：取最高等级事件作为基准，每增加 1 条同类别事件升 0.5 分
2. **跨类别叠加**：存在 2 个及以上不同类别的高风险事件时，综合评级上调一级
3. **时间衰减**：超过 30 天且无新进展的事件，风险分按 0.7 系数衰减；超过 90 天无新进展的可归档
