# 企业综合风险评估框架

## 概述

本框架从三个维度全面评估企业风险：

| 维度 | 对应技能 | 数据来源 | 核心关注 |
|------|----------|----------|----------|
| 舆情风险 | sentiment_risk_analysis | search_negative_news | 近90天负面舆情事件的分类、量化评分与管理建议 |
| 预警风险 | alert_analysis | search_alerts | 信用类、合规类等预警的逐条分析与交叉研判 |
| 风险标签 | risk_tag_analysis | get_enterprise_detail | 预警等级/RAD分/ESG分类/资产分类/风险标签的逐项诊断 |

## 分析流程

```
1. search_enterprises → ask_user(select) 选企业
2. 加载 sentiment_risk_analysis → search_negative_news → 舆情分析结论
3. 加载 alert_analysis → search_alerts → 预警分析结论
4. 加载 risk_tag_analysis → get_enterprise_detail → 风险标签分析结论
5. 三方面交叉研判 → 综合结论 + 综合风险等级 + 管理建议
```

> 三个维度的分析均有独立的技能承载，综合评估按上述顺序依次加载执行，每个维度完成后再进入下一个，避免上下文过载。

## 综合研判规则

### 交叉矩阵

| 交叉信号 | 风险含义 | 示例 |
|----------|----------|------|
| 舆情高 + 预警高 | 负面事件已触发正式预警，风险确凿 | 安全事故舆情(S3) → 环保处罚预警(红) |
| 舆情高 + 标签红 | 外部舆论压力叠加内部评级恶化 | 海外制裁舆情 → ESG分类红色 |
| 预警高 + 标签红 | 内部预警系统与风险标签体系相互印证，风险可信度高 | 多头授信预警(红) + 资产分类B1 |
| 三方面均出现红色信号 | 系统性风险，需启动最高级别应急响应 | — |
| 仅单方面出现信号 | 该维度暂未扩散到其他方面，单独评估即可 | — |

### 综合风险等级

| 等级 | 判定标准 |
|------|----------|
| LOW (低风险) | 舆情/预警/标签三方面均无红色或橙色信号，仅偶发蓝色关注 |
| WATCH (关注) | 任一方面出现橙色信号，或 2 个以上方面出现蓝色信号 |
| HIGH (高风险) | 任两方面的最高等级为红色，或多维度橙色叠加 |
| CRITICAL (严重) | 三方面均出现红色信号，或存在重大经营危机和违约风险 |
