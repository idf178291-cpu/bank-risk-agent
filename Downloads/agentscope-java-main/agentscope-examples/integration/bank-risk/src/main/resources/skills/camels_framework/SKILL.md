# 企业风险评估框架 (FICDG)

## 概述

FICDG 是通用的企业风险评估框架，适用于各类非金融企业的信用风险评估：

| 维度 | 权重 | 核心指标 |
|------|------|----------|
| F - 财务健康 | 25% | ROA ≥ 3%, 毛利率 ≥ 15%, 经营现金流为正 |
| I - 行业地位 | 20% | 市场份额, 技术壁垒, 营收增长率 |
| C - 合规声誉 | 20% | 监管处罚记录, 法律诉讼, 负面舆情 |
| D - 债务风险 | 20% | 资产负债率 ≤ 70%, 流动比率 ≥ 1.5, 利息保障倍数 ≥ 2 |
| G - 运营治理 | 15% | 管理层稳定性, 供应链集中度, 公司治理结构 |

## 各维度详细评估方法

### F - 财务健康

评估企业盈利能力和现金流状况：

| 指标 | 良好 | 一般 | 预警 |
|------|------|------|------|
| 资产收益率 (ROA) | ≥ 5% | 1%-5% | < 1% |
| 毛利率 | ≥ 25% | 10%-25% | < 10% |
| 经营现金流 | 持续为正 | 偶尔为负 | 连续2年以上为负 |
| 营收增长率 | ≥ 10% | 0%-10% | < 0% |

### I - 行业地位

评估企业在所处行业的竞争力和抗风险能力：

- 市场份额：龙头(前3) / 中游 / 尾部
- 技术壁垒：专利数量、研发投入占比
- 客户结构：客户集中度（单一客户占比 > 30% 需关注）
- 行业周期：成长型 / 成熟型 / 衰退型

### C - 合规声誉

评估企业的法律合规和公众形象风险：

| 风险等级 | 判定标准 |
|----------|----------|
| 低风险 | 近3年无重大处罚、无重大诉讼 |
| 关注 | 存在行政处罚或一般诉讼 |
| 高风险 | 被列入失信名单、实际控制人涉及刑事案件 |
| 严重 | 面临强制退市、破产清算、行业禁入 |

### D - 债务风险

评估企业的杠杆水平和偿债能力：

| 指标 | 安全 | 关注 | 危险 |
|------|------|------|------|
| 资产负债率 | < 50% | 50%-70% | > 70% |
| 流动比率 | > 2.0 | 1.0-2.0 | < 1.0 |
| 利息保障倍数 | > 3 | 1.5-3 | < 1.5 |

### G - 运营治理

定性评估企业的管理能力和治理水平：

- 管理层稳定性：近3年核心高管变更频率
- 股权结构：实际控制人持股比例、股权质押率
- 供应链安全：关键供应商集中度、替代难度
- 内部控制：审计意见类型、内控缺陷披露

## 综合风险等级判定

| 风险等级 | 判定标准 |
|----------|----------|
| 低风险 (LOW) | 各维度表现良好，无明显风险隐患 |
| 关注 (WATCH) | 1-2个维度出现预警信号，需跟踪监测 |
| 高风险 (HIGH) | 多个维度出现严重问题，存在实质性风险 |
| 严重 (CRITICAL) | 多项指标严重恶化，存在重大经营危机或违约风险 |
