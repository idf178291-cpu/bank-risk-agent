# CAMELS 银行评级体系

## 概述

CAMELS 是国际通行的银行监管评级体系，由六维度组成：

| 维度 | 权重 | 核心指标 |
|------|------|----------|
| C - 资本充足率 | 20% | CAR ≥ 8%, 核心一级资本充足率 ≥ 5% |
| A - 资产质量 | 20% | NPL ≤ 3%, 拨备覆盖率 ≥ 150%, 关注类贷款迁移率 |
| M - 管理能力 | 15% | 公司治理、内控制度、合规记录、董事会履职 |
| E - 盈利能力 | 15% | ROA ≥ 0.5%, ROE ≥ 10%, 净息差, 成本收入比 |
| L - 流动性 | 20% | 流动性比率 ≥ 25%, LCR ≥ 100%, NSFR ≥ 100% |
| S - 市场敏感性 | 10% | 利率风险敞口, 汇率风险暴露, 信用价差敏感度 |

## 各维度详细评估方法

### C - 资本充足率

评估银行资本是否足以抵御风险损失：
- 资本充足率 (CAR) = 资本净额 / 风险加权资产 × 100%
- 核心一级资本充足率 = 核心一级资本净额 / 风险加权资产 × 100%
- ≥ 8% 达标，< 8% 需关注，< 6% 严重不足

### A - 资产质量

评估银行信贷资产的风险状况：
- 不良贷款率 (NPL) = 不良贷款余额 / 贷款总额 × 100%
- 拨备覆盖率 = 贷款损失准备 / 不良贷款余额 × 100%
- NPL ≤ 3% 达标，3%-5% 关注，> 5% 高风险
- 拨备覆盖率 ≥ 150% 达标，120%-150% 关注，< 120% 不足

### M - 管理能力

定性评估银行管理层的能力和治理水平：
- 风险标签分析：是否存在"关联交易"、"股东质押"、"内控缺陷"等标签
- 监管评级趋势：基于近期事件的升/降级判断
- 合规记录：近3年监管处罚次数及严重程度

### E - 盈利能力

评估银行的盈利水平和可持续性：
- 资产收益率 (ROA) = 净利润 / 平均总资产 × 100%
- ROA ≥ 0.5% 良好，0%-0.5% 一般，< 0% 亏损
- 结合净息差、非利息收入占比综合判断

### L - 流动性

评估银行应对短期资金需求的能力：
- 流动性比率 = 流动性资产 / 流动性负债 × 100%
- ≥ 25% 达标，< 25% 不足
- 结合 LCR（流动性覆盖率）和 NSFR（净稳定资金比率）综合判断

### S - 市场敏感性

评估银行承受市场价格变动风险的能力：
- 利率风险：资产负债期限错配程度
- 汇率风险：外汇敞口占资本净额比例
- 信用价差风险：持有债券的信用评级变动敏感性

## 综合风险等级判定

| 风险等级 | 判定标准 |
|----------|----------|
| 低风险 (LOW) | 各指标均在监管要求范围内，无明显风险隐患 |
| 关注 (WATCH) | 个别指标接近或略超监管红线，需跟踪监测 |
| 高风险 (HIGH) | 部分指标超过监管红线，存在实质性风险 |
| 严重 (CRITICAL) | 多项指标严重超标，存在重大风险或违约可能 |
