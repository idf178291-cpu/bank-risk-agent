# 监管红线速查表

## 资本充足率监管要求

| 指标 | 监管要求 | 法律依据 |
|------|----------|----------|
| 资本充足率 (CAR) | ≥ 8% | 《商业银行资本管理办法》 |
| 核心一级资本充足率 | ≥ 5% | 《商业银行资本管理办法》 |
| 一级资本充足率 | ≥ 6% | 《商业银行资本管理办法》 |
| 系统重要性银行附加资本 | +1% | 人民银行、银保监会联合发布 |
| 逆周期资本缓冲 | 0-2.5% | 监管部门视经济周期调整 |

## 资产质量监管要求

| 指标 | 监管要求 | 预警值 |
|------|----------|--------|
| 不良贷款率 (NPL) | ≤ 3% | > 2% 需报告 |
| 拨备覆盖率 | ≥ 150% | < 120% 需整改 |
| 贷款拨备率 | ≥ 2.5% | < 2% 预警 |
| 关注类贷款占比 | — | > 5% 需说明原因 |
| 逾期90天以上贷款/不良贷款 | ≤ 100% | 超过则抵质押不足 |

## 流动性监管要求

| 指标 | 监管要求 |
|------|----------|
| 流动性比率 | ≥ 25% |
| 流动性覆盖率 (LCR) | ≥ 100% |
| 净稳定资金比率 (NSFR) | ≥ 100% |
| 核心负债依存度 | ≥ 60% |
| 流动性匹配率 | ≥ 100% |

## 集中度风险监管要求

| 指标 | 监管要求 |
|------|----------|
| 单一客户贷款集中度 | ≤ 10% 资本净额 |
| 单一集团客户授信集中度 | ≤ 15% 资本净额 |
| 全部关联方授信集中度 | ≤ 50% 资本净额 |
| 同业融出比例 | ≤ 50% 一级资本净额 |
| 房地产贷款集中度 | 分档管理（中资大型银行 40%，中型 27.5%） |

## 风险处置触发机制

| 触发条件 | 处置措施 |
|----------|----------|
| CAR < 8% 但 ≥ 6% | 限制分红、限制高管薪酬、提交资本恢复计划 |
| CAR < 6% 但 ≥ 4% | 限制资产增长、要求补充资本、限制新的对外投资 |
| CAR < 4% | 监管接管、强制重组、要求股东注资 |
| NPL > 5% | 暂停新增高风险授信、制定不良资产处置计划 |
| 拨备覆盖率 < 120% | 要求增加拨备计提、限制利润分配 |
| LCR < 100% | 限制中长期贷款投放、要求增持高流动性资产 |
