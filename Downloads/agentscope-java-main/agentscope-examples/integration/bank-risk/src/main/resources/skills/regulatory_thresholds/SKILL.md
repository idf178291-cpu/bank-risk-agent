# 企业风险指标参考基准

## 盈利能力基准

| 指标 | 优秀 | 良好 | 一般 | 较差 |
|------|------|------|------|------|
| ROA (资产收益率) | ≥ 8% | 3%-8% | 1%-3% | < 1% |
| ROE (净资产收益率) | ≥ 15% | 8%-15% | 3%-8% | < 3% |
| 毛利率 | ≥ 30% | 15%-30% | 5%-15% | < 5% |
| 净利率 | ≥ 10% | 5%-10% | 1%-5% | < 1% |

## 偿债能力基准

| 指标 | 安全 | 关注 | 危险 |
|------|------|------|------|
| 资产负债率 | < 50% | 50%-70% | > 70% |
| 流动比率 | > 2.0 | 1.0-2.0 | < 1.0 |
| 速动比率 | > 1.0 | 0.5-1.0 | < 0.5 |
| 利息保障倍数 | > 5 | 2-5 | < 2 |
| 有息负债率 | < 30% | 30%-50% | > 50% |

## 运营效率基准

| 指标 | 健康 | 需关注 |
|------|------|--------|
| 应收账款周转天数 | < 60天 | > 120天 |
| 存货周转天数 | < 90天 | > 180天 |
| 经营现金流/营业收入 | > 10% | < 0% |
| 现金循环周期 | < 60天 | > 150天 |

## 行业参考阈值

| 行业类型 | 毛利率参考 | 资产负债率上限 | 特殊风险 |
|----------|-----------|---------------|----------|
| 新能源 | 15%-30% | 60% | 产能过剩、技术迭代 |
| 通信设备 | 30%-50% | 50% | 技术封锁、供应链安全 |
| 新能源汽车 | 15%-25% | 65% | 补贴退坡、价格竞争 |
| 房地产 | 20%-35% | 70% | 政策调控、流动性风险 |
| 航空运输 | 10%-20% | 70% | 油价波动、汇率风险 |
| 信息技术 | 25%-45% | 50% | 技术迭代、客户集中度 |

## 风险预警触发条件

| 触发条件 | 风险信号 |
|----------|----------|
| 连续2年ROA < 1% | 盈利能力预警 |
| 资产负债率 > 70% 且持续上升 | 债务风险预警 |
| 经营现金流连续为负 | 流动性预警 |
| 实际控制人变更或股权冻结 | 治理风险预警 |
| 一年内重大诉讼超过3起 | 合规风险预警 |
| 审计意见为非标 | 会计质量预警 |
